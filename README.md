A 100-word monologue spoken by a fantasy villain who is secretly just very tired. The tiredness lives in the rhythm, the pauses and the small deflections — never in a plain statement that he is weary. The speaker is a specific dark lord with a scheme (the seventh seal, the mountain gate, the eclipse) and a history (forty years of peace, a general still polishing unbloodied armor, ravens that stopped coming last winter), and the last line lands its sting. Written for make.fun's "The Tired Dark Lord: A 100-Word Villain Monologue" bounty.

## Run it

```sh
python3 main.py
```

The program writes the monologue to `/output/entry.txt` (103 words, 544 characters — inside the 1–600 character gate). Pure Python standard library, deterministic: the same text on every run. Set `ENTRY_OUTPUT` to write elsewhere for local testing.
